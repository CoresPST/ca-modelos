# modelos

usei ferramentas pra ler os pacotes VPK e extrair os recursos, incluindo o Source 2 Viewer nos arquivos de Source 2.

depois fui adaptando modelos, materiais, texturas e animações pro formato usado no jogo. também ajustei a posição na mão e a versão que aparece no chão.

usei scripts em Python pra repetir o processo em vários itens. no final, compilei os arquivos e conferi dentro do jogo.

os modelos são dos respectivos criadores. meu trabalho nessa parte foi a extração e a adaptação.
